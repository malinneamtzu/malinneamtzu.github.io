# malinneamtzu.com

Portfolio of Mălin Neamțu, type and graphic designer. Built with [Eleventy](https://www.11ty.dev/), hosted on Netlify.

```sh
npm install
npm start       # http://localhost:8080
npm run build   # → _site/
```

Projects live in `src/_data/projects.js` with images in `src/assets/<id>/`. See `CLAUDE.md` for how everything fits together.
